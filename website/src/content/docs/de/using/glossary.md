Das sind die Wörter, die Labelyard in der Oberfläche, in der Dokumentation und in der API-Referenz benutzt. Jedes Konzept hat einen englischen und einen deutschen Begriff; verwende sie auf jeder Seite, die du schreibst.

| Begriff | Englisch | Bedeutung | Vermeide |
|---|---|---|---|
| <a id="sheet"></a>**Bogen** | sheet | Eine Seite mit selbstklebenden Etiketten, in Zellen aufgeteilt. | - |
| <a id="cell"></a>**Zelle** | cell | Eine Etikettenposition auf einem Bogen. | - |
| <a id="sheet-type"></a>**Bogentyp** | sheet type | Das Raster einer Bogenart: Größe, Aufteilung und Lage jeder Zelle. | - |
| <a id="inbox"></a>**Druckeingang** | print inbox | Der Ort, an dem Drucke aus anderen Systemen warten, bis jemand sie freigibt. | `Inbox`, `Posteingang` |
| <a id="tape"></a>**Band** | tape | Die Kassette, auf die ein Banddrucker druckt. | `Schriftband` |
| <a id="roll"></a>**Rolle** | roll | Etikettenmaterial auf einer Rolle, wie ein Etikettendrucker es einzieht. | - |
| <a id="template"></a>**Vorlage** | template | Ein gespeichertes Design, aus dem ein Etikett gedruckt wird. | `Template` |
| <a id="printer"></a>**Drucker** | printer | Ein Gerät, auf dem Labelyard druckt. | - |
| <a id="tray"></a>**Fach** | tray | Ein Papierfach eines Seitendruckers, in dem Bögen liegen. | `Schacht` |
| <a id="calibration"></a>**Kalibrierung** | calibration | Die Korrektur, damit ein Druck genau auf die Zellen eines Fachs trifft. | - |
| <a id="preview"></a>**Vorschau** | preview | Das Bild eines Etiketts, so wie es gedruckt wird. | - |
| <a id="job"></a>**Auftrag** | print job | Eine Anfrage zu drucken, von der Warteschlange bis zum Ergebnis verfolgt. | `Job`, `Druckjob` |
| <a id="batch"></a>**Stapel** | batch | Mehrere Etiketten, die zusammen in einem Zug gedruckt werden. | `Batch` |
| <a id="queue"></a>**Warteschlange** | queue | Die Reihe der Aufträge eines Druckers. Nichts druckt an ihr vorbei. | `Queue` |
| <a id="label"></a>**Etikett** | label | Das, was gedruckt und aufgeklebt wird. | `Label` |
| <a id="api-key"></a>**API-Schlüssel** | API key | Das Geheimnis, mit dem ein Programm die API aufruft. | `API-Key` |

These are the words Labelyard uses, in the interface, in the documentation and in the API reference. Each concept has one English term and one German term; use them in every page you write.

| Term | German | Meaning | Avoid |
|---|---|---|---|
| <a id="sheet"></a>**sheet** | Bogen | One page of self-adhesive labels, cut into cells. | - |
| <a id="cell"></a>**cell** | Zelle | One label position on a sheet. | - |
| <a id="sheet-type"></a>**sheet type** | Bogentyp | The layout of a kind of sheet: size, grid and where each cell sits. | - |
| <a id="inbox"></a>**print inbox** | Druckeingang | The place where prints from other systems wait until someone releases them. | - |
| <a id="tape"></a>**tape** | Band | The cassette that a tape printer prints on. | - |
| <a id="roll"></a>**roll** | Rolle | Continuous label stock on a roll, as a page printer takes it. | - |
| <a id="template"></a>**template** | Vorlage | A saved design that a label is printed from. | - |
| <a id="printer"></a>**printer** | Drucker | A device Labelyard prints on. | - |
| <a id="tray"></a>**tray** | Fach | A paper tray of a page printer that holds sheets. | - |
| <a id="calibration"></a>**calibration** | Kalibrierung | The correction that makes a print land exactly on the cells of a tray. | - |
| <a id="preview"></a>**preview** | Vorschau | The picture of a label as it will print. | - |
| <a id="job"></a>**print job** | Auftrag | One request to print, tracked from the queue to the result. | - |
| <a id="batch"></a>**batch** | Stapel | Several labels printed together in one go. | - |
| <a id="queue"></a>**queue** | Warteschlange | The line of print jobs of one printer. Nothing prints past it. | - |
| <a id="label"></a>**label** | Etikett | The thing that gets printed and stuck on. | - |
| <a id="api-key"></a>**API key** | API-Schlüssel | The secret that lets a program call the API. | `API-Key` |

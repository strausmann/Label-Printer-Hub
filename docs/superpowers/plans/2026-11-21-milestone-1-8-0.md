# Milestone 1.8.0 — Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Ship release 1.8.0 (sheets and calibration made checkable) with all 24 issues of the milestone (22 plus #412 and #413) implemented or closed with evidence, an upgrade from 1.7.1 without data loss or manual step, a documented way back, and every new API surface additive except the loosenings and tightenings the spec names.

**Architecture:** Fixes and features stay inside the existing layers: schemas in `app/schemas/`, routes in `app/api/routes/`, logic in `app/sheets/`, `app/calibration/`, `app/services/`, every print through `PrintService` / the queue (ADR 0005). New data in stored job payloads goes only into containers 1.7.1 already ignores unknown keys in (operator ruling 2026-11-21, below). Seven Alembic revisions (E1, A2, A1, C1, P1, C2, D1) in one linear chain plus the A3 startup step.

# Milestone 1.7.0 — Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Ship milestone 1.7.0 with an empty milestone: SNMP discovery in the printer form (#296), a cart that checks every item before printing (#285), the webhook quantity on the label (#284), Grocy's label printer webhook (#281), bulk resolve of unconfirmed sheet cells (#282) and the notification centre (#255, after design approval); #283 is closed by the maintainer's ruling.

**Architecture:** Backend changes stay inside the existing layers: schemas in `app/schemas/`, routes in `app/api/routes/`, logic in `app/services/` and `app/sheets/`; every print goes through `PrintService` and the queue (ADR 0005). The frontend adds one pure function per feature (payload, preview selection, notification derivation) with Vitest tests, and thin components on top. The notification centre derives its entries in the browser from queries the SSE stream already keeps live; no new event type.

**Tech Stack:** FastAPI / SQLModel / SQLite / Alembic / asyncio / pytest; React 19 + Vite + Vitest + Playwright, react-aria-components, TanStack Query/Router, lingui.

**Spec:** `docs/superpowers/specs/2026-11-14-milestone-1-7-0-design.md` (section and ruling numbers below refer to it). Issues are read with `gh api repos/strausmann/Label-Printer-Hub/issues/<n>` and `/comments`.

## Global Constraints

- Minor milestone: `feat` commits allowed; **no `!`, no `BREAKING CHANGE:` footer**, no removed or renamed response field.
- Commit scopes only from `commitlint.config.cjs` (`api`, `ui`, `webhook`, `sheets`, `integrations`, `auth`, `security`, `docs`, `decisions`, `plans`, …). Subjects lowercase, no full stop, ≤ 120 chars. Every commit body ends with `Refs #<issue>`.
- Branch: work on `milestone/1.7.0` (feature branches from it, PRs into it). Before each task: `git fetch origin && git merge --no-edit origin/milestone/1.6.0` while 1.6.0 is unreleased, `origin/main` after; re-check the file paths of the task after a merge that touched them.
- Prose names Labelyard; settings `LABELYARD_*` (the `PRINTER_HUB_*` fallback stays); browser storage keys keep `lph.` (R-0-1).
- TDD: the failing test first; every new regression test is run once against the code without the change (counter-test) and must fail **for the stated reason**.
- Mutation paths (HTTP POST, DB write) test the happy path, the backend error path and the network/upstream error path.
- No `str(exc)` of an integration or upstream error in a response (CWE-209). Example hosts use `example.invalid`.
- Every new route: OpenAPI responses documented, `cd frontend && pnpm gen:api` regenerates `src/api/schema.gen.ts`, and `backend/tests/unit/api/test_route_auth_coverage_guardrail.py` stays green.
- Website pages change in English and German in the same commit (`website/src/content/docs/…` and `website/src/content/docs/de/…`), glossary terms from `docs/glossary.toml`, German with „du“.
- UI tasks load the design skills before building: `taste-skill:design-taste-frontend`, `emil-design-eng`, `mobile-native` for phone layouts; `impeccable:impeccable` for acceptance. A new dialog, popover or panel gets a case in `frontend/e2e/short-viewport.spec.ts` (1280x500 and 390x400, keyboard covering the visual viewport). New UI gets its README screenshot (`pnpm screenshots`, view listed in `frontend/e2e/readme-screenshots.spec.ts`).
- Gates per task: backend `ruff check . && ruff format --check . && mypy app/ && pytest`; frontend `pnpm typecheck && pnpm lint && pnpm test:coverage && pnpm build`, plus `pnpm e2e` for UI tasks.

## Review Focus

1. **A token in the access log** (#281): uvicorn writes `GET /path?token=…` to `uvicorn.access`; the filter must rewrite the record **args**, not only the formatted message, because handlers format later. → Task 5, `test_access_record_token_is_redacted_in_args`.
2. **A 422 that echoes the token** (#281): a constrained `Query` parameter echoes its input. → Task 5, `test_overlong_token_answers_401_and_body_has_no_token`.
3. **Count drift between dialog and click** (#282): a job turns a reserved cell unconfirmed while the dialog is open. → Task 2, `test_resolve_all_refuses_changed_count`.
4. **A cart of 120 items or the same item twice** (#285): chunks of 50, deduplicated lookups. → Task 8, `test_check_deduplicates_identical_items`; Task 9, `chunks a cart of 120 items into three requests`.
5. **Broken local storage** (#255): private mode throws on `setItem`, an old value is not JSON. → Task 10, `falls back to memory when storage throws`.
